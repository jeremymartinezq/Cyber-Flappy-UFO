# Cyber Flappy UFO Game

A futuristic, cyberpunk-themed Flappy Bird clone with a UFO twist, built with HTML5 Canvas, TailwindCSS, and vanilla JavaScript.

## Description

Pilot your alien spacecraft through a dystopian skyline, dodging neon obstacles in this action-packed game. Experience vibrant visuals, explosive effects, and an immersive cyberpunk atmosphere.

## Features

- Cyberpunk-themed visuals with neon colors and city skyline
- Physics-based gameplay with gravity and flight mechanics
- Dynamic obstacles with random gaps
- Explosive particle effects on crash
- Score tracking with high score persistence
- Sound effects for engine boost, scoring, and crashing
- Responsive design that works on various screen sizes
- Scanline and glitch visual effects for immersion

## How to Play

1. Open `index.html` in a modern web browser
2. Click the "START MISSION" button or press SPACE to begin
3. Press SPACE or click to make your UFO fly upward
4. Navigate through the gaps between the neon pipes
5. Each successfully passed set of pipes adds 1 to your score
6. If you crash, click "REBOOT SYSTEM" to try again

## Controls

- **SPACE / MOUSE CLICK**: Activate UFO thrusters
- **SOUND TOGGLE**: Button in the top-left corner

## Technical Implementation

This game is built using:

- HTML5 Canvas for game rendering
- TailwindCSS for UI styling
- Vanilla JavaScript for game logic
- Local Storage for saving high scores and settings

## Audio Credits

For full functionality, you'll need to add sound files to the `assets` folder:

- `flap.mp3` - Sound when the bird flaps
- `score.mp3` - Sound when passing through pipes
- `crash.mp3` - Sound when crashing
- `background.mp3` - Background music (optional)
